# .github

Public GitHub organization defaults for Phaway: issue templates and pull request templates that propagate to all org repositories (public and private).

Files that require visibility from external collaborators (e.g. anyone opening an issue) live here. Internal-only defaults (SECURITY.md, CONTRIBUTING.md, reusable workflows) live in [`.github-private`](https://github.com/phaway-tech/.github-private).

GitHub only propagates issue and PR templates from a public `.github` repo — `.github-private` is limited to a subset of community health files.
